# Sovereign workbench (SIH 26117)

On-prem agentic AI workbench for confidential industrial work. TypeScript. bun. Express API + Next.js UI (shadcn/ui, TanStack Query). Ollama on localhost. Nothing leaves the box.

**Start here:** [wiki/INDEX.md](wiki/INDEX.md)  
**Agents:** [AGENTS.md](AGENTS.md)

Venue: `bun run demo` (Express `:8787` + Next `:3000`). Dev: `bun run api` and `bun run web`. `/api/*` rewrites to `127.0.0.1:8787`.
